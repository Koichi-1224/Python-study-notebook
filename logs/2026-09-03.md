## 仕組みの理解メモ

### モジュールの import

- 同じフォルダに `xxx.py` があれば `import xxx` できる
- 探す順番：実行中ファイルのフォルダ → 標準ライブラリ → `.venv` の site-packages
- import 名と pip 名が違うものがある：`sklearn` → `scikit-learn` など

### カーネル選択とターミナルの関係

- Notebook のカーネルを選ぶと、VSCode が裏でその Python（venv）を直接呼び出して実行してくれる
- PowerShell を別途 Activate しなくても、選んだ venv の環境がそのまま使われる仕組み

### drills/ の位置づけ

- `basic/` は自分の手で書く練習用（Claude は中身を触らない方針のまま）
- `drills/` は Claude 製の自動採点ドリル。ゲーム感覚のテンポ重視、進捗バー・連続正解（🔥）表示付き
- 教材の出典（松尾研究所名や固有名詞）は公開リポには書かない方針に統一

## 詰まったこと集

### 1. `ModuleNotFoundError: No module named 'numpy'`
- 原因：venv にインストールされていなかった
- 対処：`pip install numpy` → `requirements.txt` に追記 → カーネル再起動

### 2. `No module named 'sklearn.liner_model'`
- 原因：サブモジュール名のタイポ（正しくは `linear_model`）
- 学び：エラーが「トップ」で止まるか「サブ」まで出るかで、未インストールか綴りミスかを見分けられる

### 3. ドリルの問題文に教材由来の固有名詞が残っていた
- 症状：生成した問題文に「松尾研究所」「松尾くん」などの表記が残っていた
- 対処：該当箇所を洗い出し、出典名・固有名詞を一切含まないオリジナルの問題文に全面書き直し
