## 仕組みの理解メモ

### `range(start, stop, step)`
- 第3引数で「刻み幅」を指定できる。`range(1, len(steps), 2)` は奇数インデックスだけを拾うテク
- `stop` は「含まない」ルール。`len(steps)` をそのまま使えば `IndexError` にならない安全な上限になる

### 辞書の `.items()`
- `辞書名.items()` の形でキーと値のペアを1つずつ取り出せる
- `for key, value in 辞書名.items():` の形で使う。呼び出す辞書名を書き忘れると動かない

### `.append()`
- リストの末尾に要素を追加する破壊的メソッド（その場でリストを書き換える＝再代入ではない）
- 戻り値は `None`。`x = x.append(...)` と書くと `x` が `None` になって事故る
- 空リストを用意して `for` ループの中で `.append()` していく集計パターンが頻出

### `type()` とクラス名の取得
- `type(x).__name__` で「型名そのものを文字列として」取り出せる

### 苦手リストの考え方（`_state["tries"]`）
- `check()` は呼ばれるたびに問題ID別の挑戦回数（`tries`）を記録している
- ただしこの状態はカーネルのメモリ上にしかない。カーネル再起動やノートを開き直すと消える（後から遡って復元はできない）
- 苦手リストはこの `tries` を「2回以上」でフィルタしただけのもの。間違えたコードや値そのものは保存していない
- 呼び出す位置に決まりはない。`from drill import ...` を実行済みで、かつカーネルが再起動されていなければ、ノートのどこで呼んでもその時点の状態を表示する

### if 文の条件に関数を使う
- `if 関数(引数):` のように、関数の戻り値をそのまま条件式に使ってよい。呼ばれた瞬間に `True`/`False` の値に置き換わるイメージ
- 同じ呼び出しを複数回使うなら、先に変数に受けてから使い回すと読みやすい（Q4-7 の `bmi_label` が典型例）

## 詰まったこと集

### 1. `git push` が `rejected (fetch first)`
- 原因：リモート側に自分のローカルにない変更があった（別PCからの push など）
- 対処：`git pull origin main` → `git push`

### 2. カーネル再起動後に `NameError`
- 原因：カーネル再起動で変数・関数が全部消える。上のセルから再実行していなかった
- 対処：上から順に再実行、または「Run All」

### 3. `TypeError: can only concatenate str (not "int") to str`
- 原因：文字列と数値を `+` で直接連結しようとした
- 対処：f-string に書き換え

### 4. `bool()` がたまたま正解扱いになっていた（Q1-25）
- 原因：`bool()` は引数なしだと常に `False` を返すだけで、実際の比較をしていなかった
- 対処：`balance >= price` のような正しい比較式に修正
- この件をきっかけに「正解時にも模範解答を表示する」機能を追加

### 5. 辞書の値を更新したのにキーが消えた（Q2-13）
- 原因：直前の試行錯誤で `menu = {...}` と丸ごと再代入してしまい、既存のキーが消えていた
- 対処：辞書定義セルを再実行して復元してから再挑戦

### 6. if/elif/else で `NameError: feeling`
- 原因：各分岐で `print()` するだけで `feeling` 変数に代入していなかった
- 対処：各分岐で `feeling = '...'` と代入する形に修正

### 7. f-string の完全一致で不正解（Q3-4）
- 原因：「と」「は」の前後のスペースの有無で文字列が一致しなかった
- 対処：問題文の例と同じ位置にスペースを入れる

### 8. `area()` で `TypeError: got an unexpected keyword argument 'height'`（Q4-3）
- 原因：関数の引数名を `hight` とタイポしていたのに、呼び出し側は正しいスペル `height` で渡していた
- 対処：定義側の引数名を `height` に修正して、呼び出し側と揃える
- Python 3.10 以降は「Did you mean 'hight'?」のように近い綴りを提案してくれる（煽りではなく実際に役立つヒント）

### 9. `c_to_f(c)` で `NameError: name 'f' is not defined`（Q4-8）
- 原因：引数として受け取っているのは `c` なのに、関数の中では存在しない `f` を使おうとしていた
- 対処：`return f * 9 / 5 + 32` を `return c * 9 / 5 + 32` に修正。関数名につられて「変換後の名前（f）」を使いたくなるが、使えるのは受け取った引数（c）だけ
